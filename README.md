# 管家

一个人用的日常操作系统:今天做什么、为什么做、做得怎么样。纯前端,数据只存在使用者自己的浏览器里。

这个仓库里只有程序本身,没有任何人的内容。打开时它是空的;使用者在"备份"页导入自己的备份文件,内容才出现在那台设备上。

## 装到手机上

1. 用手机浏览器打开发布地址。
2. 添加到主屏幕(iPhone:分享 → 添加到主屏幕;安卓:菜单 → 安装应用或添加到主屏幕)。
3. 从主屏幕图标打开,到"备份"页导入备份文件。

之后没有网络也能打开。数据存在这个图标对应的存储里,换手机或清除数据之前先导出备份。

## 在电脑上运行

```
npm install
npm run dev
```

Windows 上也可以双击 `启动管家.bat`。

## 结构

| 位置 | 内容 |
| --- | --- |
| `DESIGN.md` | 设计规范。所有页面必须遵守。 |
| `tailwind.config.ts` | 设计值的唯一来源(间距、字号、颜色、动效)。 |
| `src/state/` | 数据结构、存取、规则(便条、连续天数、趋势、解析)。 |
| `src/pages/` | 九个板块:今日、课程与作业、训练、学习、项目、目标、人生大纲、复盘、备份。 |
| `src/seed/index.ts` | 新安装时的起始数据。发布版是空的;本机若有 `src/seed/personal/`(不入库)则用它。 |
| `public/sw.js` | 让应用离线可用。 |

## 命令

```
npm run dev           启动
npm test              跑测试
npm run lint:design   检查代码里有没有规范之外的值
npm run build         规范检查 + 类型检查 + 构建
```
